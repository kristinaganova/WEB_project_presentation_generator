Какво е системата?

Описание

Уеб приложение за създаване и управление на презентации (workspaces → презентации → слайдове) с готови шаблони, експорт и real-time collaboration.

Комуникационни парадигми

  • REST (HTTP/JSON) — външен достъп до ресурси
  • Микросервиз (PHP ↔ Node.js) — PDF генерация
  • WebSocket — синхронизация в реално време
  • AJAX (Fetch) — динамичен UI без презареждане

Архитектура

Компоненти

PHP MVC (порт 8000) + MySQL + Node.js PDF service (3001) + Node.js WebSocket service (3002, health 3003).

Диаграма

Технологии: Backend (PHP)

  • PHP MVC (Controllers/Models/Views)
  • PDO + prepared statements
  • Sessions + Auth middleware
  • TCPDF (алтернативен PDF)

Технологии: Node.js услуги

  • Express (PDF service)
  • Puppeteer (headless Chrome)
  • ws (WebSocket server)
  • CORS + health endpoints

Технологии: Frontend/Docs

  • HTML/CSS/JS + Fetch API
  • WebSocket client (auto reconnect)
  • Swagger UI + OpenAPI 3.0
  • Автоматизирани тестове

REST API: Endpoints

  • GET /api/health
  • GET /api/workspaces
  • GET /api/presentations
  • GET /api/presentations/{id}
  • POST /api/presentations
  • POST /api/slides
  • PUT /api/slides/{id}
  • DELETE /api/slides/{id}

REST API: Аутентикация

UI е session-based (PHPSESSID cookie). За API се използва Bearer token със стойност PHPSESSID (след login). Swagger: /api-docs.html

PDF микросервиз: Идея

PHP генерира HTML за презентацията и го изпраща към Node.js услуга по REST. Услугата рендерира HTML с headless Chrome и връща PDF.

PDF микросервиз: Endpoints

  • GET /health
  • POST /generate-pdf
  • POST /generate-pdf-batch

WebSocket: Как работи

  • Room per presentation (по ID)
  • Broadcast към всички клиенти в room-а
  • HTTP endpoint /broadcast за нотификации от PHP
  • Client: auto-reconnect + status indicator

WebSocket: Демо идея

Отвори една и съща презентация в 2 прозореца → редактирай слайд → виж update в реално време.

Security

  • password_hash()/password_verify()
  • Authorization по workspace + роли
  • PDO prepared statements (SQLi защита)
  • htmlspecialchars() във view-ове (XSS)

Quality

  • Error handling + логове
  • Health endpoints (8000/3001/3003)
  • Swagger “Try it out”
  • Тестове за PDF service + интеграция

Кратко демо (5 мин.)

Стъпки

  • 1) Login: /auth/login
  • 2) Swagger: /api-docs.html → GET /api/presentations
  • 3) Презентация → Export PDF (Node.js микросервиз)
  • 4) WebSocket: 2 прозореца → редакция → real-time update
